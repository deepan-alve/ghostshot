    Manual · page 1

    Three ways to let go

    1. release

      Image

      On your clipboard, and saved in ~/Pictures/Screenshots.

    2. R + release

      Text

      The words in the area, read by tesseract.

    3. F + release

      Path

      Where the file landed. Paste it in a terminal.

    Manual · page 2

    Set up

    1. Install from extensions.gnome.org.
    2. Press Print Screen, drag, release.
    3. For text, add tesseract.sudo apt install tesseract-ocr
