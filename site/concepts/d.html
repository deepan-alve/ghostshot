GhostShotGS 2

    Three ways to let go

    Release
    Image on your clipboard. File in ~/Pictures/Screenshots.
    R + release
    The words in the area, read by tesseract.
    F + release
    The file path, ready for a terminal.

    Set up

    1. Install from extensions.gnome.org.
    2. Press Print Screen, drag, release.
    3. For text: sudo apt install tesseract-ocr

    No toast for GhostShot's shots. Other notifications still show. Recording works as before.
