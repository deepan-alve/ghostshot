    Three ways to let go

    1. Release

      Image

      The shot goes to your clipboard and to ~/Pictures/Screenshots.

    2. R + release

      Text

      GhostShot reads the area with tesseract and copies the words.

    3. F + release

      Path

      Copies where the file landed, ready for a terminal or a chat.

    Set up in a minute

    1. 1Install GhostShot from extensions.gnome.org.
    2. 2Press Print Screen and drag.
    3. 3For text, add tesseract:sudo apt install tesseract-ocr

    Questions

    Does it still save the file?

    Yes. GNOME saves every shot in ~/Pictures/Screenshots, as before.

    Where did the toast go?

    GhostShot drops the "Screenshot captured" toast for its own shots. Every other notification still shows.

    Does screen recording change?

    No. In recording mode a drag only selects the area, as in stock GNOME.

    Which GNOME versions?

    GNOME Shell 45 to 50, on Wayland and X11.
