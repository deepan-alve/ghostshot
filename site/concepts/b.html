GhostShot is a GNOME Shell extension. Drag over an area and release. The shot is on your clipboard before you look for a button.

GNOME 45 to 50 · Free, GPL-3.0

Try it. Drag on the sheet. Hold R for text or F for the path.

    Set up

    1. Install from extensions.gnome.org.
    2. Press Print Screen, drag, release.
    3. For text: sudo apt install tesseract-ocr
    No toast?
    Only for GhostShot's own shots. Other notifications still show.

    Unchanged. A drag never starts a recording.
